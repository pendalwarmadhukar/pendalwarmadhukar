   → Investigate Alert

   → Document & Report

## 🚀 Featured Projects

### 🛡️ CloudShield
Cloud security project focused on identifying cloud misconfigurations, security risks, IAM issues, exposed resources, and secure configuration practices.
- **Tech:** AWS, IAM, Cloud Security Concepts
- **Key Features:** Misconfiguration detection, IAM risk review, exposed-resource checks
- **GitHub:** [CloudShield](https://github.com/pendalwarmadhukar/CloudShield)

### 🌐 NetSentinel
Linux-based network security monitoring project using Bash and Nmap for system auditing, network discovery, port scanning, service enumeration, log analysis, exposure detection, and basic risk assessment.
- **Tech:** Bash, Nmap, Linux
- **Key Features:** Network discovery, port/service enumeration, exposure & risk assessment

### 🤖 SpamGuard-AI
AI / machine-learning based project focused on spam and potentially malicious message detection.
- **Tech:** Python, Machine Learning
- **Key Features:** Message classification, spam/malicious content detection

### 💳 Credit Card Fraud Detection
Machine learning project focused on identifying potentially fraudulent financial transactions.
- **Tech:** Python, Machine Learning
- **Key Features:** Transaction analysis, fraud pattern detection
